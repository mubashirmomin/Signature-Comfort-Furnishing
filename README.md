# Signature Comfort Furnishing Website

A premium, fully responsive, multi-page business website built for a custom furniture manufacturing and repair service based in Pune. The website is designed with a luxurious aesthetic to showcase craftsmanship, drive local leads, and provide a seamless user experience across all devices.

## 🚀 Live Demo
https://signature-comfort-furnishing.signature-comfort-furnishing.workers.dev/

## ✨ Key Features

* **Modern & Premium UI/UX:** High-quality dark hero banners, elegant typography (Playfair Display & Inter), and smooth, CSS-driven hover animations.
* **Dynamic Portfolio Gallery:** Includes a custom-built JavaScript filtering system to sort projects by category (Custom Sofas, Upholstery, Bed Backs, Curtains, etc.) and an interactive lightbox for high-resolution image viewing.
* **Fully Responsive Design:** Utilizes CSS Flexbox and Grid to ensure the layout looks perfect on desktop, tablet, and mobile screens.
* **Interactive Elements:** Features a sticky navigation bar with a scrolling shrink effect, a mobile-friendly hamburger menu, and an animated FAQ accordion.
* **Lead Generation Optimized:** Integrated with direct "Click-to-Call" buttons, WhatsApp API links for instant messaging, and an embedded interactive Google Map for easy navigation.

## 🛠️ Technologies Used

This project was built entirely from scratch without the use of heavy external frameworks (like Bootstrap or Tailwind), demonstrating a strong foundation in core web technologies:

* **HTML5:** Semantic structuring for all 7 web pages.
* **CSS3:** Custom variables (CSS roots), Grid/Flexbox layouts, media queries for responsiveness, and advanced transitions/animations.
* **Vanilla JavaScript (ES6+):** DOM manipulation for the portfolio filter, lightbox, sticky header, and accordion menus.
* **Google Fonts:** Integration of 'Playfair Display' for premium headings and 'Inter' for highly readable body text.
